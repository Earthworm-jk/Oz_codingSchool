# 7일차 앱 실행화면 정리

## 1. 문서 목적

이 문서는 7일차 미션 완료를 위해 FastAPI 앱을 실행한 뒤, 프론트엔드 화면에서 각 API가 정상적으로 연결되어 동작하는 모습을 정리하기 위한 문서입니다.

실제 캡처는 User API, 환자/진료기록 API, 폐렴 예측 API가 dev에 병합되고 프론트 연결이 완료된 뒤 추가합니다.

## 2. 실행 방법

```bash
fastapi run app/main.py
```

접속 주소:

```text
http://0.0.0.0:8000/
```

로컬 브라우저에서는 보통 다음 주소로 접속합니다.

```text
http://localhost:8000/
```
