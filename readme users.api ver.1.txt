🛠 변경 및 주의사항 (v1.0 기준)
1. 주요 변경점
데이터베이스 구조 최적화: * User 모델에서 복합 키를 제거하고, id를 단일 기본 키(Primary Key)로 설정하여 외래키 연결을 안정화했습니다.

uuid 필드를 도입하여 시스템 내부 고유 식별자로 활용합니다.

외래키 관계 설정: xray_images와 users 테이블 간의 외래키 제약조건(uploader_id)을 정식으로 구축하여 데이터 참조 무결성을 확보했습니다.

자동 생성 로직 도입: 사용자 생성 시 uuid가 자동으로 할당되도록 uuid.uuid4() 모듈을 적용했습니다.

2. ⚠️ 개발/운영 주의사항(문제 발생시!)
DB 초기화 시 주의: 테이블 구조 변경이 잦을 경우, alembic 마이그레이션 파일과 실제 모델이 불일치하면 에러가 발생합니다. 항상 모델 변경 후 alembic revision --autogenerate를 통해 마이그레이션을 생성하고, alembic upgrade head로 적용하세요.

Enum 형식 엄격 준수: nationality 등 Enum 필드는 정의된 값(예: korean, foreigner)만 입력받습니다. API 요청 시 대소문자를 구분하므로 반드시 확인이 필요합니다.

비밀번호 관리: 저장된 비밀번호는 강력한 해시 알고리즘(sha256_crypt)으로 보호됩니다. 데이터베이스 직접 수정보다는 반드시 제공된 인증 API를 사용하세요.
